Porting native Android dari **TEKKEN MOBILE** (`GameMidlet`, `1.0.7`, NAMCO) dalam mode **Immersive Fullscreen Landscape (`800×480`)**, lengkap dengan **Floating HUD Cheat & Opsi** serta dukungan sentuhan penuh! 🥊⚡🔥

---

## ✨ Fitur Utama
- 🖥️ **Immersive Fullscreen Landscape (`800×480`)**: Tampilan penuh tanpa black bar dengan rotasi `-90°` yang presisi serta pilihan **Layar Penuh (Stretch)** atau **Aspek Asli (`800×480`)**.
- 👆 **Sentuhan Penuh**: Pemetaan sentuhan (`pointerPressed`, `pointerDragged`, `pointerReleased`) yang sudah disesuaikan dengan rotasi Landscape.
- ⚡ **Tombol Cheat (`⚡ CHEAT` di Kiri Atas)**:
  - Akses cepat tombol **Cheat/Debug (`*`)**, **Bonus/Unlock (`#`)**, **Serang (`FIRE`)**, serta Softkey `LSK`/`RSK`.
- ⚙️ **Tombol Opsi (`⚙ OPSI` di Kanan Atas / Tombol Back)**:
  - 📐 Mode Layar (**Layar Penuh Stretch** / **Aspek Asli `800×480`**)
  - 🎯 Pengaturan **FPS** (`15 / 20 / 25 / 30 FPS`)
  - 📳 Toggle getar tombol (`ON / OFF`)
  - 🚪 Keluar Game
